# Excel 空 Sheet 批量清理工具 - 使用说明

---

## 一、环境要求

- **Java 8 或更高版本**（绝大多数电脑已预装）
- 检查方式：按 `Win+R`，输入 `cmd`，在命令行输入 `java -version`，如果显示版本号即可

---

## 二、文件清单

将以下两个文件放到**同一个文件夹**中：

```
excel-cleaner.jar      ← 核心程序
运行.bat                ← 双击启动
```

---

## 三、使用步骤

### 方式一：处理当前文件夹（推荐）

1. 将 `excel-cleaner.jar` 和 `运行.bat` 复制到**目标文件夹**（存放 Excel 文件的那个文件夹）
2. **双击 `运行.bat`**
3. 等待命令行窗口显示处理结果
4. 查看同目录下生成的 `excel-cleaner-log.txt` 日志文件

### 方式二：命令行指定路径

```cmd
java -jar excel-cleaner.jar D:\你的文件夹路径
```

---

## 四、删除规则

| 条件 | 行为 |
|------|------|
| Sheet 仅有标题行（第一行），其余行无数据 | 删除 |
| Sheet 完全空白 | 删除 |
| Sheet 名称标注数量为 0，如 `Sheet1(0)`、`数据(0)` | 删除 |
| `可用性` 开头的 Sheet，即使标注数量为 0 | **保留** |

---

## 五、支持的格式

| 格式 | 说明 |
|------|------|
| `.xlsx` | Excel 2007+，完美保留格式和样式 |
| `.xls` | Excel 97-2003，保留格式和样式 |
| `.csv` | CSV 无 Sheet 概念，仅报告是否为空 |

---

## 六、注意事项

1. **操作前关闭 Excel/WPS**，否则文件被占用无法处理
2. 脚本**直接修改原文件**，建议首次使用前先备份重要文件
3. 处理完成后会在同目录生成 `excel-cleaner-log.txt`，记录所有操作详情
4. 如果命令行窗口一闪而过，说明 Java 未安装或 JAR 文件名不匹配

---

## 七、常见问题

**Q：双击没反应或窗口一闪而过？**
A：右键 → 用记事本打开 `运行.bat`，确认 JAR 文件名是否一致。或者在 cmd 中手动运行查看错误信息。

**Q：提示"找不到 Java"？**
A：前往 https://www.java.com 下载安装 Java 即可。

**Q：想把文件发给别人用？**
A：把这两个文件打包成 zip 发送，对方解压后放到目标文件夹双击 `运行.bat` 即可。
